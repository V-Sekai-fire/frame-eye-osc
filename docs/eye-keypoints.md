# Eye keypoints (parked)

The goal is to read the Steam Frame's infrared eye frames with an RF-DETR keypoint head and find eyelid, iris and pupil points, in place of the eye server's numbers. No code in this repo changed for it.

The state, the findings, the dataset licence table and the resume steps are in `chibifire/frame-eye-keypoints`, `docs/eye-keypoints-state.md` (private).

Resume when the render gap is to be closed. The first step is a change to the render scene (eye framing, a smooth dark iris texture, lid folds), not more parameter search; the steps and the commands are in that document.
